# toolbox

个人工具箱，存放运维脚本、服务部署、代理规则和 AI agent skills。个人应用配置由 dotfiles / chezmoi 管理。

- `scripts/`：rclone 挂载、Mouseless 安装及 Windows / WSL Shell 工具。
- `packages/`：Arch Linux 软件包清单。
- `image-tools/`：Docker Compose 服务与部署配置。
- `rules/`：代理与分流规则。
- `skills/`：AI agent skills。
- `powershell/`、`pacman-hooks/`、`templates/`、`cheats/`：平台工具、模板和参考资料。
